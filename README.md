# Система объявлений о найденных животных

Консольное приложение для публикации объявлений о найденных животных
и поиска их владельцев.

## Целевая аудитория
Владельцы потерявшихся животных, волонтёры и люди, нашедшие животных.

## Возможности
- регистрация пользователей с проверкой номера телефона;
- создание и удаление объявлений;
- просмотр всех объявлений (сначала новые);
- поиск объявлений по животному или месту;
- просмотр объявлений конкретного пользователя;
- связь с автором объявления (вывод телефона);
- статистика объявлений по видам животных;
- справка по функциям программы.

## Структура проекта
- `main.py` – точка запуска, меню приложения;
- `users.py` – работа с пользователями;
- `ads.py` – работа с объявлениями;
- `storage.py` – сохранение и загрузка данных;
- `utils.py` – вспомогательные функции и безопасный ввод;
- `data/` – JSON-файлы данных;
- `tests/` – автоматизированные тесты.

## Требования
- Python 3.10+;
- pytest;
- flake8.

Установка зависимостей:
```
pip install -r requirements.txt
```

## Запуск программы
```
python main.py
```

## Запуск тестов
```

```
