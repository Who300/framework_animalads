# Система объявлений о найденных животных

## Назначение
Приложение для публикации объявлений о найденных животных и поиска их владельцев.

## Целевая аудитория
Владельцы потерявшихся животных, волонтёры и люди, нашедшие животных.

## Предметная область
Поиск потерявшихся животных и организация взаимодействия между нашедшими их людьми и владельцами.

## Основные сущности
- Пользователь
- Объявление
- Животное
- Фотография
- Местоположение

## Основные функции
- Регистрация и авторизация пользователей.
- Создание и редактирование объявлений.
- Загрузка фотографий животных.
- Поиск и фильтрация объявлений.
- Просмотр информации о найденных животных.
- Связь с автором объявления.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
